# Code Standards

## TypeScript / React
- Run `pnpm run typecheck` and `pnpm run lint` before marking a task done
- Follow existing patterns in `web/components/` and `web/lib/`
- Use TypeScript strictly — no `any` without justification

## Git Workflow
- Work in a branch: `git checkout -b feature/<name>`
- Commit message format: `feat|fix|chore: short description`
- Open MR when ready for review

## DnD Content
- 5e rules must be traceable to PHB/DMG/MM
- Document rules decisions in `Research/` session memory
